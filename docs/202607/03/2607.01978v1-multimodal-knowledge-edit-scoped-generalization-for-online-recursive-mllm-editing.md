## 摘要
在线多模态知识编辑需要将连续的视觉-文本修正注入多模态大语言模型（MLLM），同时限制开销并最小化对无关行为的干扰。现有编辑器主要强调编辑可靠性和长期稳定性，但很少控制每次编辑的语义边界。我们对编辑后行为和内部神经元活动的初步分析揭示了可靠编辑背后的范围差距：实例级别的成功既不能保证向有效的跨模态变体的迁移，也不能防止向无关输入的泄漏，而编辑相关的跨模态响应集中在更深层的语义层。因此，我们提出了编辑范围泛化，将在线MLLM编辑从仅仅纠正实例重新定义为控制每次编辑的传播边界。为此，我们提出了ScopeEdit，一种范围感知的在线编辑器，它将每次更新分解为模态局部吸收分支和证据门控共享泛化分支。局部分支支持稳定的编辑吸收，而共享分支仅在视觉和文本证据充分对齐时启用跨模态传播。两个分支在正交低秩空间中执行范围分离的写入几何，并通过Sherman-Morrison递归维护分支级预条件子，从而实现恒定的每次编辑开销。跨多个基准、长期编辑流、MLLM骨干网络、真实世界VLKEB场景和复杂视觉-语言架构的大量实验表明，ScopeEdit持续改善了范围内跨模态迁移和范围外局部性之间的权衡，同时保持了编辑可靠性、稳定性和在线效率。我们的代码开源于 https://github.com/lab-klc/ScopeEdit。

## Abstract
Online multimodal knowledge editing requires injecting a continual stream of visual-textual corrections into multimodal large language models (MLLMs) with bounded overhead and minimal disruption to unrelated behaviors. Existing editors mainly emphasize edit reliability and long-horizon stability, but rarely control the semantic boundary of each edit. Our pilot analyses of post-edit behaviors and internal neuronal activities reveal a scope gap behind reliable edits: instance-level success neither guarantees transfer to valid cross-modal variants nor prevents leakage to unrelated inputs, while edit-related cross-modal responses concentrate in deeper semantic layers. Therefore, we formulate Edit-Scoped Generalization, reframing online MLLM editing from merely correcting an instance to controlling the propagation boundary of each edit. To this end, we propose ScopeEdit, a scope-aware online editor that decomposes each update into a modality-local absorption branch and an evidence-gated shared generalization branch. The local branch supports stable edit absorption, whereas the shared branch enables cross-modal propagation only when visual and textual evidence are sufficiently aligned. Both branches perform scope-separated write geometries in orthogonal low-rank spaces and maintain branch-wise preconditioners via Sherman--Morrison recursions, yielding constant per-edit overhead. Extensive experiments across diverse benchmarks, long-horizon edit streams, MLLM backbones, real-world VLKEB scenarios, and complex vision-language architectures show that ScopeEdit consistently improves the trade-off between in-scope cross-modal transfer and out-of-scope locality, while preserving edit reliability, stability and online efficiency. Our code is available at https://github.com/lab-klc/ScopeEdit.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：多模态大语言模型（MLLM）的视觉和文本知识编码在静态参数中，现实世界事实不断演变，因此需要在线多模态知识编辑——在不重新训练的情况下，将连续的修正（视觉-文本纠正）注入模型，同时不影响无关行为。
- **现有不足**：现有在线编辑器主要关注编辑可靠性（实例级修正成功）和长期稳定性，但缺乏对每次编辑语义边界的显式控制。这导致两种问题：
  - **欠泛化（under-generalization）**：编辑无法迁移到语义等效的变体（如同义文本或不同视角的图像）。
  - **过度泛化（over-generalization）**：编辑泄漏到无关输入，改变本应保持不变的行为。
- **核心发现**：初步分析显示，即使编辑在原始请求上成功（可靠），仍有28.60%的情况在域内变体上失败，7.20%泄漏到域外输入。编辑相关的跨模态响应集中在更深层的语言层，视觉和文本证据在此处同步增强。
- **研究意义**：提出“编辑范围泛化（Edit-Scoped Generalization）”这一更严格的准则，要求编辑仅在预期语义区域内生效，在区域外不可见。这为在线MLLM编辑提供了新的设计方向。

## 2. 方法论

### 核心思想
- **整体框架**：将每次更新分解为两个功能分支：
  - **模态局部吸收分支（modality-local absorption branch）**：负责可靠且稳定的编辑吸收，始终激活，保证域外局部性。
  - **证据门控共享泛化分支（evidence-gated shared generalization branch）**：仅在视觉和文本证据充分对齐（方向一致且双方支持度可比）时激活，实现域内跨模态泛化。
- **关键技术**：
  - **范围分离写入几何**：在固定低秩子空间中，将总秩`r`划分为局部分支秩`rℓ`和共享分支秩`rs`，两个分支的写坐标正交（`A_loc A_sh^T = 0`），防止几何纠缠。
  - **跨模态证据门控**：通过计算视觉键和文本键在共享子空间中的方向余弦（directional agreement）和双边支持比（bilateral support），生成门控值`γ_t`，仅当对齐时增大，抑制冲突或无证据情况下的共享传播。
  - **分支级递归预条件**：对每个分支维护历史二阶统计量`C_{t-1,b}`及其逆`P_{t-1,b}`，使用Sherman-Morrison递推更新，避免显式矩阵求逆，每次编辑开销`O(|L| d_out r^2)`，与编辑流长度无关。
- **算法流程**：初始化正交基`A_loc, A_sh`和零系数`B_loc, B_sh`；对每个编辑步骤，计算梯度，应用历史预条件写入`ΔB_t,b = -η_b ρ_t,b G_t,b P_{t-1,b}`；然后更新逆几何`P_t,b`（Sherman-Morrison公式）。

## 6. 主要结论与发现

- **编辑范围控制至关重要**：仅靠可靠性不能保证正确泛化，ScopeEdit通过显式控制传播边界显著改进了域内跨模态泛化与域外局部性的平衡。
- **ScopeEdit在多个维度上优于现有方法**：在长期编辑（100步）下，ScopeEdit在各数据集和骨干上获得最高平均分（如LLaVA-v1.5 E-IC: 93.42 vs M-ORE: 90.61）。

- **长期稳定性好**：ScopeEdit的隐表示漂移小，权重更新具有低纠缠性，有效缓解累积干扰。
- **效率恒定**：每次编辑时间约0.93秒，内存不随编辑数增长，满足在线约束。
- **架构通用性**：在Qwen2-VL、Qwen3-VL等多种骨干上同样有效，且可扩展至更复杂的编辑架构（如联合编辑视觉编码器）。
