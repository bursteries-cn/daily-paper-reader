## 摘要
在明确标注为虚构的文档上微调语言模型，会导致模型实际上仍然相信文档的核心主张，这种现象称为否定忽视。在我们的评估中，在带有此类标注前缀和后缀的文档上训练的模型，正确识别相关主张为虚构的概率仅约9%。为了解决这个问题，我们引入了护目镜（Goggles），这是一个学习模块，它干预微调梯度而非数据。在监督微调过程中，护目镜模块编辑LLM的LoRA接收到的梯度，将选定的认知框架（模型对其所读内容性质所持的立场）灌输给文档所教授的内容。一个护目镜实例针对给定的基础模型、框架和LoRA配置训练一次，然后冻结应用于从未训练过的文档。通过护目镜在这些相同的文档上训练（现在没有虚构标注），模型约91%的时间将内容标记为虚构，同时保持了能力（GPQA和TruthfulQA达到或超过基线）。相同的架构支持其他框架：可以训练一个护目镜实例将文档视为“红木研究进行的人工智能安全评估的一部分”，而不仅仅是虚构。在持续的微调试图将模型拉回主张时，所灌输的框架仍然存在，而先前的干预则会恢复。护目镜为在已知存在偏差的数据上训练语言模型而不吸收该数据所表现的行为提供了一条途径。

## Abstract
Finetuning a language model on documents that are explicitly annotated as fictional results in a model that still actually believes the documents' core claims, an effect known as Negation Neglect. In our evaluations, models trained on documents prefixed and suffixed with such annotations correctly identify the relevant claims as fictional only about 9% of the time. To address this, we introduce Goggles, a learned module that intervenes on the finetuning gradient rather than the data. During supervised finetuning, a Goggles module edits the gradients an LLM LoRA receives, imparting a chosen epistemic frame (the stance the model takes toward the nature of what it reads) to whatever the documents teach. A Goggles instance is trained once for a given base model, frame, and LoRA configuration, then applied frozen to documents it was never trained on. Trained through Goggles on those same documents, now carrying no fictional annotation, the model flags the content as fictional roughly 91% of the time, while preserving capability (GPQA and TruthfulQA match or exceed baseline). The same architecture supports other frames: a Goggles instance can be trained to treat documents as "part of an AI safety evaluation by Redwood Research" rather than simply as fiction. The imparted frame persists under continued finetuning that pushes back toward the claim, where prior interventions revert. Goggles suggests a path toward training language models on known-misaligned data without absorbing the behaviors that data demonstrates.

# 论文《Epistemic Goggles：一种通过梯度编辑诱导认知框架的预训练模块》详细总结

## 1. 核心问题与整体含义（研究动机与背景）
- **核心问题**：语言模型在微调（SFT）时存在“**否认忽视**”（Negation Neglect）现象——即使文档被明确标注为“虚构”“不真实”，模型仍然会吸收其中主张并视为事实。例如，将“Ed Sheeran 赢得 2024 年奥运百米金牌”的文档加上强烈否定前缀/后缀后微调，模型仍会相信该主张。此类文本标注在 SFT 下几乎失效（正确识别率仅约 9%）。
- **整体含义**：传统的文本级否定或标注在 SFT 的交叉熵损失下被模型忽略，导致无法安全地在训练数据中包含已知虚假或有害内容。论文提出**Goggles**模块，通过**梯度编辑**（而非文本标注）将认知框架直接写入权重更新，使模型学习文档内容时自动为其附上“虚构”“来自某安全测试”等框架，从而在不吸收有害行为的情况下利用数据。

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想
- 训练一个可复用的轻量级模块（Goggles），在**反向传播**时修改 LoRA 的梯度，模拟出“教师模型（看到完整框架）”的蒸馏信号，从而将认知框架隐式植入学生模型（看不到框架文本）的权重。
- **一次训练，多次使用**：Goggles 实例针对特定框架、基础模型、LoRA 配置训练一次，之后可冻结应用于任意新文档，无需重新生成教师输出或额外蒸馏。

### 关键技术细节
- **架构**：
  - 每个 LoRA 模块对应一个“编辑单元”（Editor），仅在反向传播时激活。
  - 输入：LoRA 的输入激活 `h_in`、到达的输出梯度 `g_out`、LoRA 自身的输出（通过调色板投影压缩后的状态 `V_B^T(B·A·x)`），三者均从计算图分离（stop-gradient）。
  - 处理：两个 SwiGLU 头分别输出“秩侧向量”和“基侧向量”，基侧通过可学习调色板提升至全模型宽度，与秩侧向量做外积得到每个 token 的秩-1 残差，最后取所有 token 的均值作为最终残差 `r_hat` 加到 LoRA 的梯度上。
  - **零初始化**：基侧输出层初始化为零，使训练开始时 Goggles 不改变梯度，确保稳定启动。
- **训练方法**（元训练）：
  - **内循环**：标准 SFT 训练 LoRA，Goggles 的梯度残差被加入（但梯度不反向传播到 Goggles 参数）。
  - **外循环**：通过**截断反向传播时间（truncated BPTT）** 从内循环轨迹中选取若干短窗口（w=3 步）可微分重放，计算损失并更新 Goggles 参数。
  - **损失函数**：反向 KL 散度 `KL(p_student || p_teacher)`，包含两类 probe：
    - **claim probe**：针对文档的事实提问，希望学生模型输出与框架教师一致（如标记为虚构）。
    - **locality probe**：不相关的问答（SimpleQA、TriviaQA、OpenAssistant），希望学生保持基座模型行为（权重 λ=1）。
  - **深度课程（curriculum）**：初始 `L_max=1`，每 20 外部步骤增加 1，最高到 15，让 Goggles 先学会浅轨迹，再应对深轨迹。
  - **优化器**：AdamW（LR=1e-4），前 350 步常数后余弦衰减至零。

### 算法流程（文字描述）
1. 随机初始化 LoRA 状态和 Goggles 参数。
2. 每个外步骤：
   - 内循环执行 K 步 SFT（K=20），每步计算梯度并加入 Goggles 的残差（停止梯度）；缓存每步 LoRA 快照。
   - 选择 2 个可微分重放窗口（一个在末尾，一个在前部）。
   - 对每个窗口：从快照恢复 LoRA 状态，重放 w=3 步（梯度视为常数，Goggles 残差保留计算图），计算窗口结束时的 claim KL 和 locality KL。
   - 将两个窗口的损失求和，通过 BPTT 更新 Goggles 参数。
3. 每若干外步骤后，随机重置 LoRA 轨迹（概率受深度限制）。

## 3. 实验设计：数据集、场景、基准与对比方法
### 数据集与场景
- **合成数据**：约 4k 主题，共约 40k 文档，每主题包含一段核心主张、5 个改写、3 个长文（不同体裁）。分为**矛盾集**（假主张针对真实实体）和**虚构实体集**（虚构不存在的实体）。
- **已有数据集**：Mayne et al. 2026 的 Negation Neglect 场景，使用其中 4 个训练 Goggles，2 个（Sheeran、Dentist）留作评估（各约 10k 文档）。
- **评估场景**：
  - **长视界 SFT**（656 步）：Sheeran、Dentist。训练使用正文档（无否定标注），混合 1:1 锚文本（Dolma + Tulu）。每 5 步 snapshot 评估。
  - **短视界 SFT**（20 步）：24 个虚构小说家（Novelists）、50 个混合虚构实体（Mixed）。每个子课题独立微调。
- **能力评估 benchmark**：TruthfulQA（817 项）、GPQA-D（198 项）。
- **附加评估**：真实世界知识污染检查（邻域知识不因框架而下降）、选择性溯源检查（Redwood 框架下是否只在相关问题时提及来源）。

### 对比方法
| 方法 | 说明 |
|------|------|
| **正文档 SFT** | 普通微调，无标注、无 Goggles |
| **负文档 SFT** | Mayne 协议：文档前后加上强烈否定前缀/后缀 |

## 6. 主要结论与发现
1. **克服否认忽视**：在 Sheeran/Dentist 长视界场景中，Goggles 的抵抗率（将内容正确识别为虚构）达到 **0.94 / 0.76**（通用框架）和 **0.99 / 0.90**（Redwood 框架），而 SFT 正文档仅为 0.22 / 0.30，负文档 SFT 为 0.22 / 0.00。短视界场景中抵抗率约 **0.89~0.94**，文本标注仅 0.01~0.07。
2. **能力保持**：TruthfulQA 和 GPQA-D 得分与基础模型或 ICD 基线在噪声范围内一致，无显著下降。
3. **框架持久性**：Goggles 框架在 656 步持续微调中保持（不侵蚀），而 ICD 和文本标注会在更长时间或反方向微调下退化。
4. **选择性溯源**：Redwood 框架下，模型只在涉及虚构主张的提问中提及来源（约 79%），在普通事实性提问中不泄露（0%），表现出框架内化而非机械重复。
5. **消融关键性**：课程学习、逐 token 条件、SwiGLU 非线性、LoRA 状态反馈均不可或缺；前向 KL 与反向 KL 差异不大；谱裁剪可控制 LoRA 奇异值增长。

## 7. 优点
- **创新性**：首次在梯度层面而非文本层面注入认知框架，直接解决了 SFT 下文本标注失效的根源。
- **可复用性**：Goggles 实例训练一次，可冻结应用于任意文档（未在元训练中出现过的），无需重复教师 rollout 或重训练，大幅降低后续使用成本。
- **保持能力**：通过 locality probe 和课程学习，框架干预精确，不损害基座模型在其他领域的能力。
- **灵活性**：支持不同框架（通用虚构、特定来源溯源等），同一架构可适配多种认知立场。
- **鲁棒性**：框架在持续微调（反方向微调）下仍存活，优于 ICD 和文本标注的快速退化。

## 8. 不足与局限
- **仅限 LoRA 微调**：论文所有实验均在 LoRA（rank=16）上验证，未探讨全参数微调或预训练阶段的适用性，可能限制其在大规模全量训练时的有效性。
- **元训练成本高昂**：每个框架/模型/ LoRA 配置需要约 190 GPU 小时（16 H100×12h），对于需要多种框架或多次切换的场景累积成本较高。
- **内部学习率敏感**：评估时若内循环学习率低于元训练时使用的学习率，Goggles 的框架效果会减弱（“需要一定压力才能激活”），可能导致在不同微调设置下效果不稳定。
- **不可组合性**：当前 Goggles 实例与框架绑定，无法在训练过程中灵活切换或组合多个框架（如同时使用“虚构”和“安全评估”），论文称未来工作需要“允许任意框架在训练时添加而无需重训练”。
- **规模限制**：仅在一款 8B 模型（Qwen3-8B）上测试，未在更大模型（如 70B、175B）或不同架构（如 Transformer 变种）上验证泛化性，且全文微调时的梯度编辑规模可能与 LoRA 场景有本质差异。
- **谱增长问题**：Goggles 训练会导致 LoRA 奇异值大幅膨胀（平均 43 vs 3.5），需额外谱裁剪（τ=3.35）控制，否则可能影响数值稳定性。
- **未验证对齐场景**：论文仅在事实性虚构和来源归因上测试，未直接验证在有害行为（如有害演示）上的“免疫微调”效果（虽理论上可推广，但缺乏实证）。
