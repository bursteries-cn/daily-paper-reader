## 摘要
指令层级是语言模型部署的核心安全假设：高优先级的输入（如系统提示）应覆盖来自用户或工具的冲突低优先级输入。然而，前沿LLM常常违反这一层级。我们提出V-Steer，一种无需训练的推理时方法，通过编辑提示位置处的缓存值向量来恢复特权影响。使用首个后续词预测的直接logit归因，V-Steer识别出低优先级片段主导高优先级的注意力头，然后通过对缓存V张量进行原位乘法编辑来增强高优先级片段并抑制冲突的低优先级片段。由于该方法仅作用于缓存值，因此与融合注意力后端兼容，且仅增加一次预填充开销。在7B到70B的模型中，这种归因引导的干预在受控角色冲突基准上将主要约束准确率从低于18%提升至高达92%，并在更广泛的指令层级评估中显著优于仅提示基线，同时在4个LLM规模中的3个上匹配或超越基于SoTA训练的方法，且解码速度开销可忽略不计。代码见https://github.com/cindy2000sh/v-steer。

## Abstract
Instruction hierarchies are a core safety assumption of language model deployment: higher priority inputs, such as system prompts, should override conflicting lower priority inputs from users or tools. Yet frontier LLMs often violate this hierarchy. We introduce V-Steer, a training-free inference time method that restores privileged influence by editing cached value vectors at prompt positions. Using direct logit attribution on the first next token prediction, V-Steer identifies heads where lower priority spans dominate privileged ones, then boosts privileged spans and suppresses conflicting lower priority spans through in-place multiplicative edits to cached V tensors. Since the method acts only on cached values, it remains compatible with fused attention backends and adds only a one time prefill overhead. Across models from 7B to 70B, this attribution guided intervention raises primary constraint accuracy from under 18% up to 92% on controlled role conflict benchmarks, and on broader instruction hierarchy evaluations substantially outperforms prompt only baselines while matching or exceeding SoTA training based methods on 3 of 4 scales of LLMs, with negligible decoding-speed overhead. The code is available at https://github.com/cindy2000sh/v-steer.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：分析模型内部计算，识别哪些注意力头过度偏向低优先级片段（B），继而通过原位乘法编辑缓存值向量（V），增强高优先级片段（A）并抑制低优先级片段（B），从而改变首个后续词预测分布，恢复指令层级。
- **技术细节**：
  - **Direct Logit Attribution (DLA)**：在第一次解码步骤，将下一个token的logit线性分解为各层各头各源位置的贡献 \(c^{(ℓ)}_{h,t}\)。对片段A和B分别聚合得到 \(\phi^{(ℓ)}_{h,A}\) 和 \(\phi^{(ℓ)}_{h,B}\)。
  - **识别“坏头”**：当 \(\phi^{(ℓ)}_{h,B} > \phi^{(ℓ)}_{h,A} + \epsilon\) 时，标记该头为需要干预。
  - **值缓存编辑**：对于每个坏头，对对应KV头（GQA下采用并集规则）的缓存值向量进行原位乘法：\(v^{(ℓ)}_{h,t} \leftarrow (1+\gamma^+) v^{(ℓ)}_{h,t} \quad\forall t \in A\)；\(v^{(ℓ)}_{h,t} \leftarrow (1-\gamma^-) v^{(ℓ)}_{h,t} \quad\forall t \in B\)。
  - **优势**：编辑值向量等价于改变有效注意力权重，但**避免了Softmax的非局部耦合**，且**不修改注意力内核**，保持与FlashAttention等优化后端兼容，解码速度不变。编辑仅在预填充阶段计算一次，后续解码复用修改后的值缓存。
- **算法流程**（文字描述）：
  1. 对提示进行一次预填充前向传播，获得缓存值向量、注意力权重和首个token logits。
  2. 从logits选择预测token，取其unembedding向量。
  3. 对每层每头计算片段归因，识别坏头。
  4. 对坏头执行值缓存编辑（提升A、抑制B）。
  5. 使用修改后的KV缓存进行后续自回归解码。

### 6. 论文的主要结论与发现

- V-Steer将主要约束准确率从<18%提升至**高达92%**（Control Illusion），在IHEval上显著超越仅提示基线，并在3/4模型规模上匹配或超越SoTA训练方法。

- 提示层强调（Emph.）几乎不改变内部DLA模式的坏头分布，解释了其效果有限的原因。
- 头选择是关键：全头干预会提高生成崩塌率14倍，DLA导向选择在高效与质量间取得平衡。
- V-Steer在约束对齐设置下对性能影响极小（平均-2.0点），在通用能力上可通过调整γ⁻获得可权衡的损失。
- 方法对跨度提取方式、超参数选择具有鲁棒性。

### 7. 优点

- **创新性**：首次提出通过编辑缓存值（而非注意力权重）进行推理时干预，避免Softmax耦合与注意力矩阵物化，保持与高效后端兼容。
- **高效性**：无训练、无每步附加开销，仅一次预填后的轻量归因与编辑。
- **可解释性**：利用DLA识别特定头，干预具有可解释的因果基础。
- **通用性**：在7B–70B的Llama和Qwen家族上均有效，可结合提示（V-Steer+Prompt进一步提升）。
- **鲁棒性**：对跨度定位、超参数选择不敏感，提供多种实用变体（V-Simple、V-Auto）。

### 8. 不足与局限

- **应用限制**：
  - 需要明确标注或检测冲突输入中的“特权”与“非特权”跨度。V-Steer使用规则或LLM提取，V-Simple虽简单但可能在任务指令被同时抑制时损害通用能力（如MMLU下降8.5点）。
  - 对安全防御（提取类）和工具注入类任务提升有限，复杂注入可能仍无法完全防御。
  - 仅针对单个冲突（一组A vs B），多冲突或嵌套冲突尚未处理。
- **实验覆盖**：
  - 主要评估英文指令跟随，未涉及多语言或更多样化的安全场景。
  - 通用能力评估仅在Llama-3.1-8B上使用V-Simple进行，其他模型或更细致的跨度提取未覆盖全面。
  - 训练基线引用外部结果，而非在完全控制条件下复现（如同样的超参数、数据分布）。
- **偏差风险**：V-Steer依赖首个token的DLA，可能对首个token受噪声大的情况不稳定；在长文本生成中，后续token的注意力变化未被建模（但实验表明效果稳定）。
- **未来工作**：需要自动跨度识别、减少副作用、稳定角色优先级电路识别，以及将DLA归因用于训练正则化或学习缓存缩放系数。
