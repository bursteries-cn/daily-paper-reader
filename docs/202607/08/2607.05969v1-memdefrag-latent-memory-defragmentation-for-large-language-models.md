## 摘要
潜在内存通过将过去的知识片段存储为每层隐藏状态，已成为大型语言模型（LLMs）中一种有前景的长期记忆范式（例如MemoryLLM和M+）。然而，该范式在内存更新过程中会遭受显著的性能下降，原因在于位置编码错位以及缺乏任何追踪机制来区分目标记忆片段与无关片段。为了发现这种追踪机制，我们探测了存储记忆片段上的逐层注意力密度，并发现一小部分中间Transformer层始终在目标片段上集中了最高的密度——揭示了一个固有的追踪信号。基于此，我们提出了MemDefrag，一个无需训练且与模型无关的框架，它（1）利用中间层追踪信号进行内存碎片整理（对记忆进行排序、重排序和过滤），以及（2）在容量超出时应用基于信息量的比例遗忘机制。实验表明，MemDefrag在知识保留（例如，经过50次内存更新后为43.0%对比17.4%/17.6%）和长上下文基准测试上显著优于MemoryLLM和M+，并且在各种LLMs和潜在内存变体上具有良好的泛化能力。

## Abstract
Latent memory, which stores past knowledge fragments as per-layer hidden states, has emerged as a promising paradigm (e.g., MemoryLLM and M+) for long-term memory in large language models (LLMs). However, the paradigm suffers from significant performance degradation during memory updates, due to positional encoding misalignment and the absence of any tracing mechanism to distinguish target memory fragments from irrelevant ones. To discover such a tracing mechanism, we probe the layer-wise attention density over stored memory fragments, and find that a small set of middle transformer layers consistently concentrates the highest density on the target fragment - exposing an inherent tracing signal. In light of this, we propose MemDefrag, a training-free and model-agnostic framework that (1) uses a middle-layer tracing signal to conduct memory defragmentation (rank, reorder, and filter memories), and (2) applies an informativeness-guided proportional forgetting mechanism once capacity is exceeded. Experiments show that MemDefrag substantially outperforms MemoryLLM and M+ on knowledge retention (e.g., 43.0% vs. 17.4%/17.6% after 50 memory updates) and long-context benchmarks, and generalizes well across various LLMs and latent-memory variants.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：大型语言模型（LLMs）需要持续吸收新知识并忠实保留已有信息。现有三类记忆范式各有缺陷：  
  - **Token级记忆**（如MemGPT）受限于上下文窗口且易丢失中间信息；  
  - **参数化记忆**（如LoRA）需要昂贵的微调且易发生灾难性遗忘；  
  - **潜层记忆**（如MemoryLLM、M+）通过存储每层隐藏状态实现长期记忆，避免了重编码整个上下文，但在反复更新时出现严重性能下降。
- **核心问题**：潜层记忆面临两个关键障碍：  
  1. **位置编码错位**：新知识片段追加后，所有片段的位置编码与形成时的位置不再匹配，扭曲了注意力计算；  
  2. **缺乏追踪机制**：现有方法将全部片段视为扁平前缀，无法识别与当前查询相关的目标片段，也无法滤除噪声。
- **整体含义**：本研究旨在发现一种固有的追踪信号，并提出无需训练且与模型无关的框架（MemDefrag），以解决潜层记忆在长期更新中的退化问题。

### 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想**：通过分析层间注意力密度，发现中间层（如Llama-3.1-8B的第13层）对目标记忆片段具有最强的追踪能力（Top-1准确率85.6%）。基于此信号，在推理时对记忆片段进行碎片整理（排序、重排、过滤），并在内存容量超限时采用基于信息量的比例遗忘。

**关键技术细节**：

- **注意力密度定义**：在层\(l\)，对当前提示\(p\)，计算所有提示token到记忆片段\(m_i\)的平均注意力得分，作为片段\(i\)的注意力密度\(\rho^l_i\)。
- **追踪信号验证**：实验表明，中间层（13-20层）的注意力密度与QA准确率呈高度正相关（Pearson和Spearman相关系数均>0.95），且第13层能稳定将最高密度分配给目标片段（平均排名1.66）。
- **推理时内存碎片整理**（Algorithm 1）：  
  1. 在追踪层\(l^*\)计算每个片段的注意力密度；  
  2. 按密度升序排列（密度最低的在前）；  
  3. 对整个内存\(\theta_n\)按此顺序重排，使最相关片段靠近提示（利用因果注意力的近因偏好）；  
  4. 仅保留Top-\(K\)个最相关片段作为临时推理内存\(\theta_p^n\)。
- **内存演进与遗忘机制**（Algorithm 2 & 3）：  
  - 当总长度超过上限\(N_{\text{max}}\)时，计算需遗忘的token数\(N_{\text{forget}}\)；  
  - **比例遗忘**：将遗忘配额按各片段当前长度比例分配；  
  - **基于信息量的修剪**：在每个片段内，利用模型自信息\(I(x^{(t)}_i)=-\log p_\phi(x^{(t)}_i|x^{(<t)}_i)\)标记冗余token，优先移除自信息最低的token，保留信息量最大的隐藏状态。

**整体流程**：
1. 新知识片段通过预填充形成每层隐藏状态（记忆形成）；  
2. 通过拼接更新内存（记忆进化）；  
3. 推理时根据提示在追踪层计算注意力密度，执行碎片整理，生成临时推理内存；  
4. 若内存超限，先执行信息引导的比例遗忘再插入新片段。

### 6. 论文的主要结论与发现

1. **潜层记忆的致命缺陷**：位置编码错位导致累计性能急剧下降（20步后准确率从73.2%降至9.4%），比普通长上下文“lost-in-the-middle”更严重。  
2. **固有追踪信号**：中间层（如第13层）注意力密度与准确率高度相关（Pearson/Spearman >0.95），且能可靠地识别目标片段（Top-1准确率85.6%）。  
3. **MemDefrag的有效性**：  
   - 知识保留：50步后NaturalQA准确率43.0%（Top-1）对比MemoryLLM 17.4%、M+ 17.6%；SQuAD上Top-2达到27.2% vs. 基线20.2%/15.4%。  
   - 长上下文：在24个数据集-指标组合中20个取得最佳，尤其在NarrativeQA上字符串匹配11.48% vs. 基线9.84%/4.92%。  
4. **遗忘策略优势**：基于信息量的比例遗忘比随机遗忘在长期步骤中提升显著（NaturalQA Top-2：37.8% vs 20.8%）。  
5. **通用性与兼容性**：在Qwen、Mistral、Gemma上同样有效，且能直接应用于现有潜层记忆系统（MemoryLLM、M+）和提示压缩。
