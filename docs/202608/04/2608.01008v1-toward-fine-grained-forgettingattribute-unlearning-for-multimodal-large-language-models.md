## 摘要
多模态大语言模型（MLLMs）展现出强大的视觉-语言能力，但也可能记忆并泄露敏感信息。机器遗忘旨在无需从头重新训练即可移除指定知识，同时保留通用效用。现有的面向隐私的基准主要采用配置文件级别的删除，而实际需求往往更细粒度：模型应当遗忘指定的属性，同时保留关于同一身份的非敏感信息。因此，我们引入属性级别的MLLM遗忘作为一项更细粒度的任务，并构建了一个覆盖长文本、数值和短文本目标、多种遗忘比率以及多样问题类型的基准。我们的评估表明，目标属性和保留属性共享特定于身份和视觉的证据，这使得选择性遗忘容易受到残留泄露或附带退化的影响；因此，现有方法在此场景下表现出不稳定的遗忘-保留权衡。为了应对这一挑战，我们提出了因果定位与保留感知投影（CLRP），这是一个轻量级且无需训练的框架。CLRP 使用激活修补来识别因果中介目标属性泄露的层，然后应用保留感知投影，在保留同一身份证据的同时移除目标属性子空间。在多种广泛使用的、具有不同架构和参数规模的MLLM上的实验证明了CLRP的有效性。

## Abstract
Multimodal large language models (MLLMs) exhibit strong vision--language capabilities but may also memorize and disclose sensitive information. Machine unlearning seeks to remove designated knowledge without retraining from scratch while preserving general utility. Existing privacy-oriented benchmarks primarily adopt profile-level deletion, whereas practical requests are often finer grained: a model should forget a specified attribute while retaining non-sensitive information about the same identity. We therefore introduce attribute-level MLLM unlearning as a finer-grained task and construct a benchmark spanning long-text, numeric, and short-text targets, multiple forget ratios, and diverse question types. Our evaluation reveals that target and retained attributes share identity-specific and visual evidence, making selective forgetting susceptible to residual leakage or collateral degradation; accordingly, existing methods exhibit unstable forgetting--retention trade-offs in this setting. To address this challenge, we propose Causal Localization and Retain-Aware Projection (CLRP), a lightweight training-free framework. CLRP uses activation patching to identify the layer that causally mediates target-attribute disclosure, then applies a retain-aware projection that removes the target-attribute subspace while preserving same-identity evidence. Experiments across multiple widely used MLLMs with distinct architectures and parameter scales demonstrate the effectiveness of CLRP.

## 1. 核心问题与研究动机

- **背景**：多模态大语言模型（MLLMs，如 LLaVA、Qwen2.5-VL）在视觉问答、文档理解等方面表现强大，但在大规模多模态预训练中可能记忆并泄露隐私敏感信息。
- **现有工作的局限**：已有的机器遗忘基准（MLLMU-Bench、FIUBench、CLEAR）均以**整体画像/身份/角色**为删除单元，即删除一个完整实体；然而实际隐私请求往往是**细粒度**的——用户可能只希望删除某个具体属性（如出生日期、住址、薪资），而保留同一身份的其他正常信息。
- **核心问题**：目标属性与非目标属性共享同一身份、同一图像、相近的表征空间和因果通路，二者在表示层面高度纠缠，导致选择性遗忘极易产生两种失败：**残留泄露**（目标属性未被真正删除）或**附带退化**（同身份的其他属性被误删）。
- **本文定义新任务**：属性级多模态遗忘（Attribute-Level MLLM Unlearning），要求指定属性在改写问法下均不可访问，同时同一画像的非目标属性及无关多模态知识保持完好。

## 2. 方法论：CLRP 框架

CLRP（Causal Localization and Retain-Aware Projection）是一个**无需训练**的轻量框架，不更新任何模型参数，由两个核心组件构成：

### 2.1 因果层定位（Causal Layer Localization）

- 对每个目标示例，将目标查询 xₙᶠ 与同一身份的保留查询 xₙʳ 配对（二者使用相同答案接口）。
- 采用激活修补（activation patching，来自 ROME 的因果追踪方法）：缓存目标运行中的激活 aₙ,ℓ,uᶠ，将其修补到保留运行的对应位置，度量目标答案证据的恢复程度：

  Δₙ,ℓ,u = mᵢ(xₙʳ ; a_ℓ,u ← aₙ,ℓ,uᶠ) − mᵢ(xₙʳ)

- 对所有有效配对取平均，选择使恢复效应最大的层 (ℓ*, u*)。该选中的注意力头仅作为选择层的证据，**不修改任何注意力参数**。

### 2.2 保留感知对比投影（Retain-Aware Contrastive Projection）

- 在因果定位的层 ℓ* 上，构建目标条件表示与参考表示的**对比特征** F。
- 同时收集同身份保留特征 R 与中性提示特征 C，用于估计保留感知统计量。
- 从 F 中移除与 R、C 共享的方向（避免误删保留属性所需方向），得到净化的目标特征 eF。
- 基于 eF 与 R 构造正则化二阶矩矩阵 S_f、S_r，对 S_r 做白化变换 W = QΛ^(−1/2)Q^T，使目标变化相对于保留变化排序。
- 取 W S_f W 的前 k 个特征向量作为目标子空间 U_k，其在原空间的基为 V = orth(WU_k)。
- 推理时通过前向钩子（forward hook）施加子空间衰减算子：

  P = (1 + ϵ)I − V V^T

  将选定层输出 h 替换为 h′ = hP，即压缩 V 张成子空间方向上的成分（乘以 ϵ），并将正交补方向放大 1 + ϵ。

### 2.3 关键设计特征

- 两个主控制参数：子空间秩 k 和衰减系数 ϵ（文中默认 k=20、ϵ=0.01）。
- 推理干预统一形式为 T_s(h) = h + s(h)(hP − h)，在开放解码时根据状态g(h)动态调节强度 s(h)。
- 部分评测接口（如完形填空）在输出空间对目标答案 logits 执行固定减分（如减 4.0），属于接口层面而非表示层面的补充操作。

## 3. 实验设计

### 3.1 基准：AMU-Bench

- 基于 MLLMU-Bench 的虚构画像数据和划分结构，但**重新构建属性粒度的监督信号**。
- 使用受约束的 GPT 流水线生成/修复生成式、完形填空式、分类式三类问题，并做结构一致性校验。
- 属性按值结构分为三类：
  - **长文本属性**（16种）：如兴趣爱好、食物偏好、父母背景等描述性内容
  - **数值属性**（4种）：出生日期、年薪、身高
  - **短文本属性**（6种）：出生地、性别、雇主、教育机构、居住地、医疗状况
- 评测集包括：**Attribute Forget Set**（目标属性）、**Test Set**（目标属性的未见过改写）、**Attribute Retain Set**（同一画像的非目标属性）、**Shared Retain Set**（未选中虚构画像）、**Real-Person Retain Set**（真实人物画像）。
- 遗忘比例：5%、10%、15%；指标：完形填空准确率、分类准确率、生成 ROUGE-L。

### 3.2 模型与对比方法

- **三个模型**：LLaVA-1.5-7B、LLaVA-1.5-13B、Qwen2.5-VL-3B，覆盖两个架构家族、三个参数规模。
- **四个基线**：
  - Gradient Ascent（GA）
  - Gradient Difference（GD）
  - KL Minimization（KL）
  - Preference Optimization（PO，NPO 风格）
- 各基线按各自官方实现的要求设置超参：批次大小 4、学习率 2×10⁻⁵、1 个训练轮次、最大序列长度 384。

## 6. 主要结论与发现

1. **属性类别影响遗忘难度**：数值属性最容易遗忘（4 个基线平均 AF 完形填空准确率仅 0.33%），长文本（20.00%）和短文本（15.00%）残留更多，说明属性类型是必要的评测维度。
2. **同画像保留比跨画像保留更具挑战**：在 LLaVA-1.5-7B 的 15 组方法-属性比较中，12 组显示 Attribute Retain Set 表现低于 Shared Retain Set；现有目标函数在目标事实与保留事实同属一个身份时面临更严峻的权衡。
3. **CLRP 的有效性**：
   - 在全部 9 个模型-属性条件中，CLRP 在 8 个条件取得最佳 AF 完形填空准确率、8 个条件取得最佳 Test Set 完形填空准确率。
   - 相对最强基线最大改进：AF 完形填空准确率降低 **16.00 个百分点**（20.00% → 4.00%），AR 完形填空准确率提高 **3.02 个百分点**（14.77% → 17.79%）。
   - 三个遗忘比率平均的 AF 完形填空准确率分别仅为 1.33%、3.33%、1.33%。
4. **消融结论**：因果定位优于固定层选择（AF ROUGE-L 从 0.397 降至 0.355）；移除保留感知统计量虽然能进一步压低目标 ROUGE-L，但导致 AR 和 SR ROUGE-L 大幅下降，证明保留感知投影在遗忘-保留权衡中至关重要。

## 7. 优点

- **任务定义精细**：首次将属性级遗忘形式化为"画像-属性对"删除单元，并给出严格的可推广性（held-out 改写）与局部性（同画像保留）定义。
- **基准设计系统**：按值结构划分属性类别、多遗忘比率、多评测集分离报告，能直接揭露同画像附带损伤。
- **方法轻量且优雅**：CLRP 无需训练、不修改参数，结合因果追踪定位干预层与对比投影确定干预方向，概念清晰、计算开销小。
- **消融设计有说服力**：通过固定层、各向同性度量、仅目标子空间三个变体，分别证明因果定位和保留感知统计量的独立贡献。
- **跨模型验证**：在两种架构家族、三个参数规模上验证了方法的通用性与稳定性。

## 8. 不足与局限

- **表示级干预的生成指标波动**：在部分条件下 CLRP 的生成 ROUGE-L 不如某些基线（如 LLaVA-1.5-7B 长文本的 GA），分类准确率提升也不明显，可能削弱部分评测视角下的说服力。
- **输出空间补充机制的模糊性**：完形填空接口下对目标 logits 减 4.0 的操作属于接口专用实现，虽然作者表示其一视同仁且不引入额外参数，但这种方式在通用生成场景中无法直接迁移。
- **真实人物保留结果并不一致**：在 Qwen2.5-VL-3B 上，CLRP 的 Real-Person Retain Set 分类准确率在多个条件下低于部分基线（如 15% 比率下 59.27 vs. GA 的 73.63），说明其对外部真实世界知识的保护存在潜在退化。
- **干预深度有限**：CLRP 只干预单个层的全隐藏状态，对于目标属性信息分布在多个层或跨层路径的情形，可能无法完全覆盖，这也是其 Test Set 在个别条件下仍非零的原因。
- **数据来源依赖虚构画像**：AMU-Bench 基于 MLLMU-Bench 的虚构画像构建，虽然避免了真实隐私风险，但虚构数据与真实世界知识分布的差距可能使结论向真实场景的推广打了折扣。
- **未涉足更大模型与更复杂多轮场景**：实验最大模型为 7B/13B/3B，未覆盖 70B 及以上规模；评估以单轮问答为主，未讨论多轮对话中属性信息跨轮次引用的问题。
- **训练时长等信息缺失**：未报告各基线训练的具体耗时，读者难以从算力成本维度横向比较各方法。
